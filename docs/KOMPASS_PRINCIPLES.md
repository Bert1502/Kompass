# KOMPASS-Grundsätze

Die folgenden Regeln sind für die Entwicklung von KOMPASS verbindlich:

- B56 ist der einzige energetische Rechenkern.
- KOMPASS führt keine eigenen DIN V 18599-Berechnungen durch.
- ThermCAD bleibt für Wärmebrückennachweise zuständig.
- Keine IFC-Auswertung implementieren.
- Architekturänderungen nur auf ausdrücklichen Auftrag.
- Build und Tests müssen nach jeder Änderung erfolgreich sein.
