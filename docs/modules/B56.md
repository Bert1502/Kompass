# Modul B56

## Zweck und Systemgrenze

B56 ist der einzige energetische Rechenkern. KOMPASS importiert,
validiert, archiviert und verarbeitet B56-Exporte, führt jedoch keine
eigenen Berechnungen nach DIN V 18599 durch.

ThermCAD bleibt für Wärmebrückennachweise zuständig. Eine
IFC-Auswertung gehört nicht zum Umfang des Moduls.

## Technischer Status

Stand: 24. Juli 2026

Der technische Importpfad ist durchgängig implementiert:

1. Die API und der Desktop-Client nehmen B56-Dateien projektbezogen
   entgegen.
2. Dateipfad, Existenz, Dateigröße, Dateiendung und OpenXML-Signatur
   werden geprüft.
3. Für die Datei wird ein SHA-256-Hash berechnet.
4. Dubletten werden innerhalb eines Projekts erkannt. Die Konfiguration
   kann einen erneuten Import ausdrücklich erlauben.
5. Erfolgreich angenommene Dateien werden in einem projektbezogenen
   Archiv abgelegt. Vorhandene Archivziele werden nicht überschrieben.
6. Die Archivkopie kann durch einen erneuten Hashvergleich verifiziert
   werden.
7. Der OpenXML-Leser übernimmt Arbeitsblätter, Zeilen, Zelladressen,
   Spalten und Werte in das B56-Arbeitsmappenmodell.
8. Die Pipeline erkennt tabellarische Bereiche.
9. Erfolgreiche Importe werden mit Metadaten in SQLite registriert.
10. Die API stellt Importergebnis und projektbezogene Importhistorie
    bereit. Interne Archivpfade werden nicht nach außen gegeben.

Fehler beim Lesen oder Verarbeiten hinterlassen weder einen
Registereintrag noch eine verwaiste Archivdatei. Temporäre
API-Uploaddateien werden auch bei Ablehnung oder Abbruch entfernt.

## Noch nicht fachlich abgeschlossen

Die Pipeline erkennt Tabellen, ordnet sie aber noch keinem verbindlichen
B56-Fachmodell zu. Deshalb bleiben aktuell:

- `ImportierteTabellen` gleich 0;
- `ImportierteBauteile` gleich 0;
- `ImportierteKennwerte` gleich 0;
- `ImportierteModernisierungsalternativen` gleich 0.

Für jede erkannte, aber nicht zugeordnete Tabelle wird eine Warnung
ausgegeben. Dieses Verhalten ist beabsichtigt: Ohne bestätigte
B56-Exportstruktur darf KOMPASS keine Spaltenbedeutungen oder
energetischen Inhalte erraten.

## Voraussetzung für den fachlichen Import

Vor der Implementierung der Tabellenzuordnung werden benötigt:

1. mindestens eine repräsentative, möglichst anonymisierte
   B56-Exportdatei;
2. die unterstützte B56-Version beziehungsweise Exportvariante;
3. eine verbindliche Beschreibung der Arbeitsblätter, Tabellen,
   Spalten und Einheiten;
4. die Zuordnung zu Bauteilen, Kennwerten und
   Modernisierungsalternativen in KOMPASS;
5. erwartete Ergebnisse für mindestens einen fachlichen
   Akzeptanzfall;
6. ein ausdrücklicher Auftrag für die daraus folgende fachliche oder
   architektonische Erweiterung.

## Abschlussbewertung

Der generische B56-Dateiimport ist technisch stabil und abgesichert.
Der fachliche B56-Datenimport ist erst abgeschlossen, wenn die
verbindliche Exportstruktur vorliegt, die Zuordnung ausdrücklich
beauftragt wurde und die erwarteten Fachdaten in einem
End-to-End-Akzeptanztest nachgewiesen sind.
