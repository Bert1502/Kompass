# Berichte

Dieses Verzeichnis enthält technische Bestandsaufnahmen, Prüfberichte und zeitpunktbezogene Analyseergebnisse.

Berichte sollen Erstellungsdatum, untersuchten Stand, Vorgehen und Ergebnis nachvollziehbar festhalten. Die bestehende technische Baseline verbleibt bis zu einer gesonderten Aktualisierung unter `docs/TECHNICAL_BASELINE.md`.
