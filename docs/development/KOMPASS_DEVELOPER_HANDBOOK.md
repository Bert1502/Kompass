# KOMPASS Developer Handbook

## Projektziel

KOMPASS unterstützt Energieberater. B56 bleibt der einzige Rechenkern.

## Architekturregeln

-   Keine energetischen Eigenberechnungen.
-   ThermCAD nur für Wärmebrücken.
-   Keine IFC-Auswertung.

## Prozess

1.  Bauteilberechnung
2.  Bilanzierung
3.  Wärmeschutznachweis
4.  Sommerlicher Wärmeschutz
5.  Wärmebrückennachweis
