# GLOSSARY

| Begriff | Bedeutung |
|---|---|
| Projekt | Klammer für Gebäude, Importe, Projektmodell, Kosten, Förderung, Dokumente und Berichte |
| B56 | alleiniger energetischer Rechenkern |
| Bestand | B56-Ausgangsberechnung |
| Variante | eigener Plan- oder Berechnungsstand in B56 |
| Modernisierungsalternative | in einer Variante definierte Maßnahme oder Kombination; bis zu neun je Variante |
| Maßnahmenpaket | Kombination mehrerer Maßnahmen, oft als Modernisierungsalternative einer gesonderten Variante |
| B56-Bauteilcode | unverändert zu erhaltende Bauteilreferenz |
| Snapshot | unveränderliche, versionierte Abbildung eines Imports |
| Projektmodell | bearbeitbare Arbeitsgrundlage |
| Nutzungsprofil | bevorzugter Begriff; „Zone“ nur bei technischem B56-Bezug |
| praktische Wirtschaftlichkeit | Bewertung nach Real-/Bilanz-Abgleich |
