# B56

## Zweck
Import und Archivierung von B56-Excel-Exporten.

## Formate
- `.xlsx`
- `.xlsm`

## Pipeline
Datei prüfen → SHA-256 → Original archivieren → Blätter klassifizieren → freigegebene Felder lesen → validieren → Snapshot → Vorschau → Commit.

## Regeln
- keine DIN-V-18599-Berechnung
- keine Änderung des Workbooks
- Snapshot mit Parser- und Payload-Version
- Energiebilanz, Energiebericht, Nutzungsprofile und Neubau erst nach Feldfreigabe erweitern
